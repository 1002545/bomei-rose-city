博美meme
========

运行方法（游戏使用绝对路径 /assets/…，必须在本目录的根路径上用静态服务器打开，不能双击 index.html）：
- Windows：双击「启动游戏.bat」，浏览器会打开 http://localhost:8000/
- macOS / Linux：终端里运行 sh start.sh，然后打开 http://localhost:8000/
- 也可以用任意静态服务器，例如 npx serve -l 8000

推荐使用新版 Chrome、Edge 或 Safari（需要 WebGL2）。

本压缩包是纯静态版本，不包含服务器接口。NPC 使用本地日程和有界决策，不请求 /api/city-logic。购物仅使用游戏币，不涉及真实支付。

版本 59：商品先加入各店购物篮，核对并确认后才扣除游戏币；未结账商品保留。商店和对话界面增加紧凑布局、独立滚动区和触控按钮；NPC 对话结合当前地点、时间和已完成购买。原有存档键和商品价格保持不变。

版本 60：第一视角使用 1.62 米眼高；移动碰撞、实例物体碰撞、自由跟随和手动回正改进；电梯镜头跟随已有角色高度。没有改变角色模型、酒店、城市几何或静态素材。已通过代码和离线控制器测试；尚未进行真实浏览器 WebGL、移动设备或帧率验证。
